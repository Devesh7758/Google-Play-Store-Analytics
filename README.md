# Google Play Store Analytics Dashboard Project

## Overview
This project contains interactive data analytics dashboards created using Python, Pandas, and Plotly based on the Google Play Store dataset.

The project includes multiple dashboard tasks focused on:
- Ratings analysis
- Reviews analysis
- Installs trends
- Revenue comparison
- Bubble chart analytics
- Choropleth maps
- Stacked area charts
- Time-series analysis

---

## Dataset Used
- Play Store Data.csv
- User Reviews.csv

---

## Technologies Used
- Python
- Pandas
- Plotly
- Jupyter Notebook
- pytz

---

## Tasks Completed

### Task 1
Average Rating and Reviews by Category using Dual Axis Chart.

### Task 2
Global Installs Choropleth Map by Category.

### Task 3
Average Installs vs Revenue for Free and Paid Apps.

### Task 4
Time Series Trend Analysis of Installs by Category.

### Task 5
Bubble Chart Analysis between App Size and Rating.

### Task 6
Stacked Area Chart for Cumulative Installs Over Time.

---

## Features
- Interactive dashboards
- Time-based visibility conditions
- Category translations
- Advanced filtering
- Data cleaning and preprocessing
- Dark themed visualizations
